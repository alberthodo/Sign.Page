# Contributing to Sign.page

Sign.page is open source client review and approval for freelancers—folders, review links, signatures, and feedback without client accounts.

**Full guide:** [docs/contributing.md](docs/contributing.md) (setup, PR checklist, database notes).

## How can I contribute?

- [Report a bug](https://github.com/alberthodo/Sign.Page/issues/new)
- [Suggest a feature](https://github.com/alberthodo/Sign.Page/issues/new)
- [Start a discussion](https://github.com/alberthodo/Sign.Page/discussions)
- [Submit a PR](https://github.com/alberthodo/Sign.Page/compare) — read [docs/contributing.md](docs/contributing.md) first

**Security:** see [SECURITY.md](SECURITY.md) (no public issues for vulnerabilities).
